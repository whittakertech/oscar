WhittakerTech::Oscar::Taxonomy

A validated, immutable taxonomy: the set of declared states and transitions for one host model (or a named base). All shape errors raise InvalidTaxonomyError at construction time — there’s no such thing as a partially-valid Taxonomy.

Constants

ConstantValue
ALLOWED_TOP_KEYS%i[initial states transitions]
ALLOWED_STATE_KEYS%i[destroyable locked]
ALLOWED_TRANSITION_KEYS%i[from to past escapes_lock]

Errors

All under WhittakerTech::Oscar, all inheriting Error < StandardError:

ErrorRaised when
ErrorBase class. Also raised directly by Stateful#oscar_taxonomy_config when called before oscar_taxonomy has been declared
InvalidTaxonomyErrorAny malformed taxonomy shape at declaration time
UndeclaredTransitionErroroscar_transition! called with an undeclared name, or the current state isn’t in that transition’s from: list
LockedStateErrorA transition blocked by a locked state without escapes_lock: true, or destroy from a non-destroyable state
ProtectedVerbErrorA transition/past name collides with destroy/delete/update, or with a pre-existing method on the host class
UnknownBaseErrorbase: names a Symbol not registered in config.bases

WhittakerTech::Oscar::VerbGenerator

Runs at oscar_taxonomy declaration time; generates the bang-verb and past-tense predicate for every declared transition.

WhittakerTech::Oscar::ScopeGenerator

Runs at oscar_taxonomy declaration time; generates a named scope per declared state plus all_states.

MethodNotes
new(host_class, taxonomy)
define!Generates one scope per state (filtered by both resource_type and state) plus all_states. Never calls default_scope

WhittakerTech::Oscar::Status

The append-only status card model, backed by Poly::Stack on the polymorphic oscar_statuses table (shared across every Oscar-managed model).

Association / columnNotes
resourcebelongs_to :resource, polymorphic: true
stateString, required
verbString, required — the transition name that produced this card
transitioned_atDateTime, required
is_prime / superseded_by_idPoly::Stack columns — “current” = superseded_by_id.nil? && is_prime?

Status.prime (from Poly::Stack) scopes to only-current cards; used throughout oscar_state and the generated per-state scopes.
