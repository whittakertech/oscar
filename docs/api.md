## WhittakerTech::Oscar (module)

### Constants

| Constant | Value |
|---|---|
| `TRANSITION_EVENT` | `'oscar.transition'` — the `ActiveSupport::Notifications` event name fired by every `oscar_transition!` call |

### Module methods

| Method | Returns | Notes |
|---|---|---|
| `table_name_prefix` | `String` | `'oscar_'` |
| `configuration` | `Configuration` | Memoized global instance, initialized on first call |
| `configure { |config| ... }` | `void` | Yields `configuration`, then eagerly validates every `config.bases` entry as a `Taxonomy` — raises `InvalidTaxonomyError` here if any base is malformed |
| `reset_configuration!` | `Configuration` | Replaces the global configuration with a fresh default. Test-suite use (`after` hooks) |
| `instrument_transition(record, from:, to:, verb:)` | `void` | Fires `TRANSITION_EVENT` via `ActiveSupport::Notifications.instrument`, payload `{ resource_gid:, from:, to:, verb: }` |
| `on_transition(&block)` | subscriber | Subscribes `block` to `TRANSITION_EVENT`, yielding the payload hash. Returns the subscriber (`ActiveSupport::Notifications.unsubscribe` to remove) |

## WhittakerTech::Oscar::Taxonomy

A validated, immutable taxonomy: the set of declared states and transitions
for one host model (or a named base). All shape errors raise
`InvalidTaxonomyError` at construction time — there's no such thing as a
partially-valid `Taxonomy`.

### Constants

| Constant | Value |
|---|---|
| `ALLOWED_TOP_KEYS` | `%i[initial states transitions]` |
| `ALLOWED_STATE_KEYS` | `%i[destroyable locked]` |
| `ALLOWED_TRANSITION_KEYS` | `%i[from to past escapes_lock]` |

### Class methods

| Method | Returns | Notes |
|---|---|---|
| `new(hash)` | `Taxonomy` | Validates immediately; raises `InvalidTaxonomyError` |
| `deep_merge(base, override)` | `Hash` | Key-by-key merge: an override redeclaring a state/transition wins for that entry only, sibling entries from `base` survive untouched |

### Instance methods

| Method | Returns | Notes |
|---|---|---|
| `initial` | `Symbol` | The taxonomy's initial state |
| `states` | `Hash{Symbol => Hash}` | Normalized to `{ destroyable:, locked: }` per state |
| `transitions` | `Hash{Symbol => Hash}` | Normalized to `{ from: [Symbol...], to:, past:, escapes_lock: }` per transition |
| `state?(name)` | `Boolean` | Whether `name` is a declared state |
| `destroyable?(state_name)` | `Boolean` | |
| `locked?(state_name)` | `Boolean` | |
| `transition?(name)` | `Boolean` | Whether `name` is a declared transition |
| `transition(name)` | `Hash` | Fetches the normalized transition, or raises `UndeclaredTransitionError` |

## Errors

All under `WhittakerTech::Oscar`, all inheriting `Error < StandardError`:

| Error | Raised when |
|---|---|
| `Error` | Base class. Also raised directly by `Stateful#oscar_taxonomy_config` when called before `oscar_taxonomy` has been declared |
| `InvalidTaxonomyError` | Any malformed taxonomy shape at declaration time |
| `UndeclaredTransitionError` | `oscar_transition!` called with an undeclared name, or the current state isn't in that transition's `from:` list |
| `LockedStateError` | A transition blocked by a locked state without `escapes_lock: true`, or `destroy` from a non-destroyable state |
| `ProtectedVerbError` | A transition/past name collides with `destroy`/`delete`/`update`, or with a pre-existing method on the host class |
| `UnknownBaseError` | `base:` names a `Symbol` not registered in `config.bases` |

## WhittakerTech::Oscar::VerbGenerator

Runs at `oscar_taxonomy` declaration time; generates the bang-verb and
past-tense predicate for every declared transition.

| Constant | Value |
|---|---|
| `PROTECTED_VERBS` | `%w[destroy delete update]` |

| Method | Notes |
|---|---|
| `new(host_class, taxonomy)` | |
| `define!` | Generates `#{name}!` and `#{past}?` per transition; raises `ProtectedVerbError` on any unsafe collision |

## WhittakerTech::Oscar::ScopeGenerator

Runs at `oscar_taxonomy` declaration time; generates a named scope per

| Method | Notes |
|---|---|
| `new(host_class, taxonomy)` | |
| `define!` | Generates one scope per state (filtered by both `resource_type` and `state`) plus `all_states`. Never calls `default_scope` |

## WhittakerTech::Oscar::Stateful (concern)

Include on a host model to give it a taxonomy-driven lifecycle state
machine.

### Class methods

| Method | Returns | Notes |
|---|---|---|
| `oscar_taxonomy(base:, **hash)` | `void` | `base:` is required, no default. See [Usage](usage/) for full resolution rules |
| `oscar_taxonomy_config` | `Taxonomy` | Raises `WhittakerTech::Oscar::Error` if `oscar_taxonomy` hasn't been declared |

### Instance methods

| Method | Returns | Notes |
|---|---|---|
| `oscar_state` | `Symbol` | Current state, resolved from the most recent status card (or the taxonomy's `:initial`) |
| `oscar_state?(name)` | `Boolean` | |
| `oscar_transition!(name)` | `WhittakerTech::Oscar::Status` | Executes a declared transition inside `with_lock`; returns the newly created status card |

Plus generated instance methods per taxonomy: `<transition>!`, `<past>?`,
and a `<state>` scope per state on the class.

## WhittakerTech::Oscar::Status

The append-only status card model, backed by
[`Poly::Stack`](https://github.com/whittakertech/poly) on the polymorphic
`oscar_statuses` table (shared across every Oscar-managed model).

| Association / column | Notes |
|---|---|
| `resource` | `belongs_to :resource, polymorphic: true` |
| `state` | `String`, required |
| `verb` | `String`, required — the transition name that produced this card |
| `transitioned_at` | `DateTime`, required |
| `is_prime` / `superseded_by_id` | `Poly::Stack` columns — "current" = `superseded_by_id.nil? && is_prime?` |

`Status.prime` (from `Poly::Stack`) scopes to only-current cards; used
throughout `oscar_state` and the generated per-state scopes.
